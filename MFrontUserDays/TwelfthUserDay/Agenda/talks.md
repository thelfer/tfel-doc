# Overview of `TFEL-5.2` and `MGIS-3.2`

- Thomas Helfer
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Antoine Martin
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.

The latest releases of TFEL (Version 5.2) and MGIS (Version 3.2)
introduce significant enhancements and new features aimed at improving
performance, usability, and functionality. This abstract provides a
concise overview of the key highlights and improvements in these
versions.

## TFEL Version 5.2 Highlights

1. **Support for TDLS Library:**
   - TFEL now supports the Tiny Device-callable Linear Solvers (TDLS)
     library, which provides direct linear solvers for small dense
     systems. This support is designed for maximum GPU performance and
     can be enabled explicitly during compilation.

2. **New TFEL/Math Features:**
   - The `StridedCoalescedView` class has been introduced to create
     tensorial objects with coalescent memory access, improving
     efficiency on GPUs.
   - The Walpole basis for transverse isotropic fourth-order tensors has
     been added, enhancing mathematical capabilities.
   - Quantities have been deeply refactored to improve maintainability,
     error messages, and reduce the size of generated symbols.

3. **New TFEL/Material Features:**
   - Homogenization methods have been enhanced, allowing modifications
     to the microstructure and supporting user-defined distributions of
     spheroids.

4. **The `generic-parallel` interface for material properties:**

   - This interface supports backends like `STLPar`, `CUDA`, `HIP`,
     `SYCL`.

## MGIS Version 3.2 Highlights

New Features:

- Scripts to define environment variables for MGIS have been introduced,
  ensuring proper setup for different systems and compilation options.
- Save/restore operations in `MaterialStateManager` and
  `MaterialDataManager` have been enhanced, allowing precise control
  over saved and restored data.
- Support for quantities has been added, enabling the assignment of
  units to floating-point numbers.
- Temporary views can now be used in "assignment" operators and the
  `assign` function, improving code flexibility.

## Conclusion

The releases of TFEL Version 5.2 and MGIS Version 3.2 bring significant
advancements in performance, usability, and functionality. These updates
include support for new libraries, enhanced build systems, improved
mathematical capabilities, and better configuration management. The
introduced features and improvements aim to provide a more robust and
efficient framework for users, facilitating better integration and
performance in various applications.

# Intégration du comportement de composites à fibres dans le calcul de structure à partir de tenseurs morphologiques

- Antoine Martin
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Mikaël Gueguen
  - Institut Pprime, CNRS
- Mhadji Abdoussalam
  - Institut Pprime

![](img/AMartin.png)

In this talk we focus on the implementation of a multiscale method for
simulating the behaviour of a fiber-reinforced thermoplastic industrial
composite. We successfully account for the complex geometry of the fiber
distribution at the microscale while ensuring a computationally
efficient behaviour integration at the macroscale

We focus on linear elastic behaviour but the material properties vary
throughout the mesh. The homogenization method is based on the
pre-computation of microstructural tensors which are stored and used at
the behaviour integration. This implementation demonstrates the
possibility of incorporating efficiently pre-computed external data into
the core of the constitutive behaviour.

## Acknowledgements

This research was conducted within the framework of the AnoHonA ANR
project.

# Alternative methods for the calibration of the Drucker-Prager/Cap model, application to the MOX fuel shaping

- Baptiste Spanu
  - CEA, DES, ISEC, DMRC, Univ Montpellier, Marcoule, France
- Adrien Socié
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LDOP, 13 108 St Paul lez Durance, France.
- T. Rebillon
  - CEA, DES, ISEC, DMRC, Univ Montpellier, Marcoule, France
- Jean-Philippe Bayle
  - CEA, DES, ISEC, DMRC, Univ Montpellier, Marcoule, France
- Thomas Helfer
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Guillaume Bernard-Granger
  - CEA, DES, ISEC, DMRC, Univ Montpellier, Marcoule, France

Uniaxial cold die compaction is a key step in the fabrication of MOX
(mixed oxide, UO2/PuO2) fuel pellets, as it strongly affects their final
quality, particularly dimensional tolerances and cracks density. This
work investigates the mechanical behaviour of MOX powders during
compaction. Powders have been produced by the COCA (CObroyage-Cadarache)
process. The die compaction was also investigated through a dedicated
Finite Element Simulation. The powder behaviour is described using a
porous elastoplastic constitutive law under finite strains based on the
Modified Drucker–Prager/Cap model, implemented in MFront
[@helfer_introducing_2015] and integrated into the Licos/Cast3M
framework [@helfer_licos_2015;@spanu_experimental_2026].

![Relative density (RD) distribution after double-action compaction of UO2
powder for a pellet geometry with chamfer and dishings](img/RelativeDensity-spanu.png){width=50%}

The model parameters were calibrated using Hencky strain measurements,
while the amount of material and the number of experimental measurements
were optimized through an inverse analysis using Uranie software. The
overall methodology was then validated through dedicated experimental
tests. This framework provides a predictive tool for studying the
influence of powder properties and tooling geometry on MOX powder
compaction behaviour and, ultimately, on pellet quality, including
dimensional accuracy and density distribution.

# Application of MANTA to the description of brittle fracture.

- Pedro Nava Soto
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Thomas Helfer
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Pierre Girié
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Livio Colombani
  - CEA Cadarache, IRESNE, DES, DEC, SESC, LMCP, 13 108 St Paul lez Durance, France.
- Jean-Michel Scherer
  - Mines Paris, Université PSL, Centre des Matériaux (MAT), UMR7633 CNRS, Versailles, 78000, France
- Jacques Besson
  - Mines Paris, Université PSL, Centre des Matériaux (MAT), UMR7633 CNRS, Versailles, 78000, France
- Olivier Fandeur
  - CEA Saclay, DES, ISAS, DM2S, SEMT, LM2S, 91191 Gif-sur-Yvette, France
- Adrien Jaccon
  - CEA Saclay, DES, ISAS, DM2S, SEMT, LM2S, 91191 Gif-sur-Yvette, France

In this talk, we study the ability of gradient damage models to describe
the brittle fracture behaviour of materials. We focus on the following
problems:

- the modelling of crack closure,
- the numerical analysis of fuel pellet brittle fracture behaviour by laser heating.

The numerical simulations were carried out on the `Manta` solver and the
behaviour laws were implemented in `MFront`.

## Modelling of crack closure

Physically, crack lips can have large relative movements and may come
into contact. Current gradient damage models in the literature can take
into account this behaviour by defining a tension/compression asymmetry
via elastic energy decomposition. This strategy is limited to very small
relative movements and induces artificial stresses across the crack
lips.

We introduce a new strategy based on the coupling of gradient damage
models with a third medium approach. As it will be presented, this
strategy allows us to eliminate the artificial stresses across the crack
lips while modelling contact even under large relative movements.

## Numerical analysis of fuel pellet brittle fracture behaviour by laser heating

Owing to their radioactive nature, experimental investigations of
brittle fracture under representative operating conditions remain
particularly challenging.

To experimentally reproduce the thermal loading experienced by the
pellets, laser heating tests are commonly performed over durations of a
few seconds.

It will be presented a numerical assessment of micromorphic cohesive
gradient damage models to describe these experiments.

# A Work-In-Progress `MFront` interface for the explicit dynamics code (Open)Radioss

- Fernando Oleo Blanco
  - Empresarios Agrupados - Ghesa, C/ de Magallanes, 3, Chamberí, 28015 Madrid, Spain

A few years ago the company Altair (now part of Siemens) opensourced
their commercial explicit dynamics solver RADIOSS (a descendant of the
same family as LS-DYNA) under the OpenRadioss brand. This presented an
enormous improvement to the state of open source explicit dynamics and
the study of rapid transients, including FSI and particles. Today
(Open)Radioss comes with a large variety of material models, fracture
criteria and many advanced features. However, developing new or custom
material laws is not trivial. For these reasons an effort was started in
order to bring MFront support for (Open)Radioss and enable a large
number of pre-made laws and a large, powerful and easy-to-use material
toolkit within the explicit code.

The interface as it stands today is limited, buggy and not as ergonomic
as others. So people interested in this work are more than welcome to
help and test the interface.

# Simulation of Static Strain Ageing and prediction of its impact on the fracture toughness properties of C-Mn steel welds

- Ronan Riverie
  - Université de Lyon, INSA Lyon, MATEIS – UMR CNRS 5510 F-69621 Villeurbanne Cedex, France
  - CEA Saclay, DES, ISAS, DM2S, SEMT, LISN, 91191 Gif-sur-Yvette, France
- Déborah Clément
  - Université Paris-Saclay, CEA, Service d'Etudes Mécaniques et Thermiques (SEMT), 91191, Gif-sur-Yvette, France
- Ghassen Ben Salem
  - Framatome, Ingénierie mécanique (DTIM), 92084 Paris la Défense Cedex, France 
- Stéphane Marie
  - Framatome, Ingénierie mécanique (DTIM), 92084 Paris la Défense Cedex, France 
- Véronique Massardier
  - Université de Lyon, INSA Lyon, MATEIS – UMR CNRS 5510 F-69621 Villeurbanne Cedex, France
- Sylvain Dancette
  - Université de Lyon, INSA Lyon, MATEIS – UMR CNRS 5510 F-69621 Villeurbanne Cedex, France

As-welded C-Mn steel joints from the Main Steam Lines (MSLs) of
Pressurised Water Reactors (PWRs) are sensitive to Static Strain Ageing
(SSA). At the microstructural scale, this phenomenon relies on the
segregation of nitrogen solutes to dislocations during an ageing heat
treatment subsequent to a prestraining mechanical treatment.
Macroscopically, the resulting dislocation pinning affects the overall
tensile behaviour, leading to material hardening and the manifestation
of plastic instabilities, specifically the Lüders phenomenon.

Capitalising on the extensive experimental campaign, comprising tensile
and fracture toughness test data, a dedicated phenomenological
transferability framework was developed to numerically predict, via
Finite Element (FE) simulations, the impact of SSA on the risk of
brittle failure using the Beremin model. This approach required
indirectly accounting for the thermomechanical history across each
metallurgical state: as-welded, strained and strain aged, via the
integration of the local stress field governed by a specific
constitutive law.

The effects of SSA on the material behaviour were modelled using the
elastic-viscoplastic KEMC framework, which includes an extra
ageing-induced hardening contribution governed by the relaxation of an
internal ageing time to phenomenologically account for solute
segregation at dislocations. This model was further updated to
accommodate the peculiar responses exhibited following the complex
prestraining mechanical history through the incorporation of nonlinear
kinematic hardening. The local constitutive integration was implemented
in MFront to be used in the Cast3M global FE solver. A dedicated
three-step calibration process for the KEMC law, relying on tailored
optimisation methods, was implemented to first fit the global hardening
behaviour before identifying the ageing parameters that dictate both the
Lüders peak and plateau, and finally calibrate the definitive hardening
rule that drives the apparent macroscopic yield drop observed on the
load-CMOD response for the strained state relative to the as-welded
state. Finally, parameter identification and subsequent application of
the Beremin model successfully reproduced the general isolated
embrittlement effects induced by prestraining and the ageing heat
treatment, yet the numerical predictions were found to be overly
conservative.

# Open-source implementation of a flexible nonlocal scheme using MFront/OpenGeoSys

- Ammar Airoud Basmaji
  - Institut für Geotechnik, TU Bergakademie Freiberg, Gustav-Zeuner-Str. 1, 09599 Freiberg, Germany
- Mehran Ghasabeh
  - Institut für Geotechnik, TU Bergakademie Freiberg, Gustav-Zeuner-Str. 1, 09599 Freiberg, Germany
- Dmitri Naumov
  - Institut für Geotechnik, TU Bergakademie Freiberg, Gustav-Zeuner-Str. 1, 09599 Freiberg, Germany
- Thomas Nagel
  - Institut für Geotechnik, TU Bergakademie Freiberg, Gustav-Zeuner-Str. 1, 09599 Freiberg, Germany

![](img/Nonlocal_OGS_MFront.png)

Nonlocal integration is one possible regularization strategy used in the
modeling of softening geomaterials
[@Bazant2002; @Manica2018; @Parisio2018]. Compared to gradient-enhanced
formulations, it has the advantage of requiring no additional degrees of
freedom and being compatible with different coupling strategies.
Previous work has pointed out various limitations of different
types of nonlocal models [@rolshoven2003nonlocal], which has led to the
adoption of over-nonlocal models in some studies based on one-dimensional 
considerations.

We have implemented a scheme that gives the user flexibility in choosing 
nonlocal or over-nonlocal models of different types using `MFront` and `OpenGeoSys`.
The implementation is geared towards easy and robust use, a flexible
choice of weighting functions, and availability within all coupled
mechanical processes. We demonstrate the application of the scheme to
models that achieve softening via damage evolution or softening laws
related to plastic state variables in 1D and 2D settings. Comparisons are made
to a previous implementation without MFront interaction.

The final application case is a transversely isotropic clay model
accounting for damage as well as elastic, viscous and plastic
deformation mechanisms.

# The `TDLS` library: fast tiled linear solvers for implicit `MFront` behaviours

- Tristan Chenaille¹,²
- Francesca Cuteri¹
- Raphaël Prat¹
- Guillaume Latu¹

1. CEA Cadarache, IRESNE, DES, DEC, SESC, LDOP, 13 108 St Paul lez Durance, France.
2. Aix-Marseille University, Mathematics and Computer Science Doctoral School, France.

![&nbsp;](img/TDLS_tiled_LU_GPU.png)

In a mechanical simulation, the behaviour is integrated at every
integration point, independently of the others. This makes behaviour
integration a good candidate for GPUs. However, implicit behaviours are
typically integrated with a Newton method. Each of its iterations builds
and solves a small linear system, which puts a lot of pressure on GPU
registers. Variables that do not fit are then evicted to slow GPU
memory. The performance of `MFront`'s linear solve routine suffers from
this, and none of the existing GPU linear algebra libraries helps.

This talk presents a tiled LU solver designed for this regime, which is
embedded in the open-source
[`TDLS`](https://github.com/trsxvz/TDLS/tree/main) library. Its main
focus is to reduce register pressure and to enhance data locality and
reuse. To do this, one thread solves one system. The matrix, the
right-hand side and the pivots may each live in registers or in remote
memory. The matrix is processed as a grid of small square tiles.
Wherever the rest lives, the tiles of the current step are held in
registers. Furthermore, pivoting stays inside the current diagonal tile
unless the best local candidate is too small. The performance gains are
impressive: on an NVIDIA H100 GPU, for a Norton viscoplastic behaviour
with 12 unknowns, this solver accelerates the behaviour integration by a
factor of about 6.

This work was motivated by GPUs, but
[`TDLS`](https://github.com/trsxvz/TDLS/tree/main) is released as a
portable header-only `C++-20` library. It can run on all kinds of GPUs,
but also on CPUs, where it performs well too.
[`TDLS`](https://github.com/trsxvz/TDLS/tree/main) support is available
in the development version of `TFEL` (master branch) and will be part of
`TFEL` releases from 5.2 onwards. When enabled, `MFront` generates
behaviours that call [`TDLS`](https://github.com/trsxvz/TDLS/tree/main)
in place of its default linear solve routine. We will show how to enable
it and what to expect.
